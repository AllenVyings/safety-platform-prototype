⚠️ 常见问题

问题 1: Python 未找到

错误：'python' 不是内部或外部命令

解决: 安装 Python https://www.python.org/downloads/

问题 2: 端口被占用

错误：Address already in use

解决: 使用其他端口 python -m http.server 8081

问题 3: 浏览器无法访问

错误：localhost 拒绝了连接

解决: 确保 HTTP 服务器正在运行，查看命令行窗口是否有输出

📞 需要帮助？

如果遇到问题，请检查：

  1. Python 或 Node.js 是否正确安装
  2. 命令行是否在项目目录
  3. 端口 8080 是否被占用
  4. 防火墙是否阻止
