# 任务管理模块规划

> 创建时间：2026-08-25
> 状态：需求确认中

---

## 一、模块定位

| 项目 | 内容 |
|------|------|
| 模块名称 | 任务管理 |
| 所属端口 | 政府端 |
| 菜单位置 | 「履职报告管理」上方 |
| 模块关系 | 上游（生成任务）→ 下游「检查记录管理」（提交检查结果） |

**核心功能**：统一管理码上排查、专项调度、交叉检查三类任务。

## 三、数据设计

### 任务数据模型

```javascript
{
  id: 'RW2026040101',           // 任务编号
  name: '南山区月度排查',        // 任务名称
  type: '码上排查',              // 任务类型：码上排查/专项调度/交叉检查
  typeTag: 'tag-blue',          // 标签样式
  domainSmall: '农贸市场',       // 领域小类
  target: 'XX市场管理有限公司',   // 检查对象
  targetType: '企业',           // 对象类型：企业/项目/重点场所
  assignee: '张科',             // 责任人/单位名称
  assigneeType: 'person',       // 指定类型：person/unit
  status: '待处理',             // 状态：待处理/已处理/已超期
  statusTag: 'tag-orange',      // 状态标签样式
  deadline: '2026-04-01',       // 截止时间
  checklist: '农贸市场日常检查表', // 关联检查表
  source: '自动生成',           // 来源：自动生成/手动创建
  createTime: '2026-03-25'      // 创建时间
}
```

### 示例数据分布

- 码上排查任务：5-8 条（模拟自动生成）
- 专项调度任务：3-4 条（模拟手动创建）
- 交叉检查任务：2-3 条（模拟手动创建）

### 4.2 筛选条件

| 筛选项 | 类型 | 选项 |
|--------|------|------|
| 任务类型 | 下拉 | 全部 / 码上排查 / 专项调度 / 交叉检查 |
| 状态 | 下拉 | 全部 / 待处理 / 已处理 / 已超期 |
| 领域小类 | 下拉 | 从 domain-data.js 动态加载 |
| 关键词 | 输入框 | 搜索任务名称、检查对象 |

### 4.3 操作按钮

| 状态 | 可用操作 |
|------|----------|
| 待处理 | 查看 / 催办 / 编辑（专项调度/交叉检查可编辑） |
| 已处理 | 查看 |
| 已超期 | 查看 / 督办 |

### 4.4 新增任务弹窗

**表单流程**：
1. 选择任务类型（专项调度 / 交叉检查）
2. 选择领域小类 → 联动加载检查对象
3. 选择检查对象（企业/项目/重点场所）
4. 填写任务名称
5. 指定责任人
6. 设置截止时间
7. 选择关联检查表（可选）
8. 提交创建

### 4.5 任务详情弹窗

右侧抽屉式，显示：
- 任务基本信息
- 关联检查记录（如有）
- 操作历史
