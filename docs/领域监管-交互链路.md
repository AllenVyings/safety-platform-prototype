## 二、左侧树导航交互

| 操作 | 交互结果 | 触发函数 |
|------|----------|----------|
| 点击「领域大类」节点（如公共场所类） | 展开/折叠下属领域小类；右侧隐藏Tab，显示该大类下的领域汇总表 | `selectNode()` → `updateDetail()` |
| 点击「领域小类」节点 | 右侧显示3个Tab，默认展示「监管总览」的管控对象明细 | `selectNode()` → `updateDetail()` |
| 点击 root（南山区应急管理局） | 展开全部大类、折叠小类；右侧显示全部领域汇总 | `selectNode('root')` |
| 搜索框输入关键词 | 匹配节点高亮展开，不匹配节点隐藏 | `filterTree()` |
| 点击「展开/收起」按钮 | 全局展开或折叠所有树节点 | `toggleExpand()` |

**关键状态**：`currentNode`（root / cat-* / domain-*）

## 三、监管总览 Tab

### 3.1 状态 A：选中 root 或行业大类

**展示**：领域汇总表（分页）

| 元素 | 交互行为 | 数据/函数 |
|------|----------|-----------|
| 统计卡片（4张） | 只读展示 | 领域小类数、管控对象总数、未关闭隐患数、平均隐患整改率 |
| 汇总表格 | 分页展示 | `renderDomainSummary()` |
| 「配置」按钮 | 进入**领域配置页**（覆盖层） | `gotoDomainConfig(id)` |
| 「查看详情」按钮 | 选中该领域，下钻到管控对象明细 | `viewDomainDetail(id)` |
| 分页组件 | 切页/改每页条数/跳转 | `domainSummaryGoPage()` / `domainSummaryChangeSize()` |

**表格列**：序号 | 领域小类名称 | 责任科室 | 管控对象数 | 绿码数 | 黄码数 | 红码数 | 隐患整改率 | 操作

### 3.2 状态 B：选中领域小类

**展示**：该领域下的管控对象明细表（分页）

| 元素 | 交互行为 | 数据/函数 |
|------|----------|-----------|
| 统计卡片（4张） | 只读展示 | 管控对象数、绿/黄/红码数、未关闭隐患数、隐患整改率 |
| 「批量配置责任人」按钮 | 打开**配置责任人弹窗** | `openAssignModal(domainId)` |
| 全选复选框 | 勾选当前页所有对象 | `toggleAllObjects()` → `updateSelectedCount()` |
| 单行复选框 | 勾选对象，用于批量配置 | `updateSelectedCount()` |
| 对象表格 | 分页展示 | `renderObjectDetail()` |
| 「查看」链接（已配置） | `postMessage` 跳转「管控档案」页 | `viewObjects(domainId)` |
| 「配置」链接（未配置） | 打开**配置责任人弹窗** | `openAssignModal(domainId)` |
| 分页组件 | 切页/改每页条数/跳转 | `objectDetailGoPage()` / `objectDetailChangeSize()` |

**表格列**：复选框 | 管控对象名称 | 对象类型标签 | 责任人 | 责任科室 | 安全码图标+文字 | 未关闭隐患 | 隐患整改率 | 操作

### 4.2 状态 B：选中领域小类

**展示**：四层递进配置 + 全部配置列表

```
⓪ 责任科室配置（下拉选择）
    ↓
① 检查表配置（表格+开关+新增/编辑/删除）
    ↓
② 扫码责任配置（依赖①，无检查表时禁用）
    ↓
③ 隐患责任配置（表格/卡片+开关+新增/编辑/删除）
```

## 六、领域配置页（独立覆盖层）

**入口**：汇总表「配置」按钮 / 任务配置 Tab「配置」链接
**触发**：`openDomainConfig(domainId)`

### 页面结构

```
┌─────────────────────────────────────────┐
│ ← 返回  监管总览 / 大类 / 小类        保存配置 │
├─────────────────────────────────────────┤
│  23 个对象 · 已配置 14 · 未配置 9              │
├─────────────────────────────────────────┤
│  ▓ 责任科室配置                            │
│    责任科室：[下拉]                         │
├─────────────────────────────────────────┤
│  ▓ 任务配置                                │
│    1. 检查表 [表格]  [+ 新增检查表]         │
│    2. 扫码责任 [卡片]    3. 隐患责任 [卡片]  │
├─────────────────────────────────────────┤
│  ▓ 对象批量指派                            │
│    Step1 选择范围 [类型/科室/关键词筛选]     │
│    [对象列表：复选框/名称/类型/责任人/科室]   │
│    Step2 指派目标 [科室] [责任人] [+添加到草稿]│
│    Step3 草稿规则（X条 · 影响Y个对象）       │
│    [规则1：N个对象 → 科室 · 责任人] [删除]   │
├─────────────────────────────────────────┤
│                              [取消] [保存配置] │
└─────────────────────────────────────────┘
```

### 交互流程

```
1. 选择责任科室（可选，默认本单位）
2. 配置检查表/扫码责任/隐患责任（可选）
3. 批量指派：
   a. 筛选对象列表（类型/科室/关键词）
   b. 勾选未配置对象（已配置的禁用不可选）
   c. 选择目标科室 + 责任人
   d. 「添加到草稿」→ 生成一条规则
   e. 可重复 a-d 添加多条规则（支持重叠冲突检测 ⚠）
4. 点击「保存配置」：
   - 保存责任科室到 DOMAIN_SUMMARY
   - 按草稿规则顺序应用到 OBJECT_DETAILS（后覆盖前）
   - 更新 assigned 计数
   - 关闭配置页，返回监管总览
5. 点击「返回/取消」：
   - 有草稿时弹出确认「是否放弃」
   - 无草稿直接返回
```

### 关键状态：`configState`

| 字段 | 说明 |
|------|------|
| `domainId` | 当前配置的领域ID |
| `objects` | 该领域下管控对象副本 |
| `filterType/filterDept/filterKeyword` | Step1 筛选条件 |
| `selectedIdx` | 当前勾选的对象索引数组 |
| `targetDept/targetPerson` | Step2 指派目标 |
| `targetConfigDept` | ⓪责任科室配置值 |
| `drafts` | Step3 草稿规则数组（rangeIds/dept/person） |

## 七、弹窗交互清单

| 弹窗 | DOM ID | 触发方式 | 功能说明 |
|------|--------|----------|----------|
| **配置责任人** | `modal-assign` | 批量配置按钮 / 行内「配置」链接 | 选择管控对象 → 选择责任人（可多选）→ 责任科室 → 配置模式（追加/覆盖）→ 确认 |

## 八、数据流转关系

```
TREE_DATA（静态树结构）
    │
    ├── DOMAIN_SUMMARY（领域汇总数据）
    │       ├── id, name, cat, objects, assigned, total
    │       ├── greenCode, yellowCode, redCode, hazards
    │       ├── checkRate, hazardRate, dept
    │       │
    │       ├── OBJECT_DETAILS（管控对象明细，按 domainId 索引）
    │       │       ├── name, type, person, dept, code, hazards, rate
    │       │       ↑ 被「配置责任人弹窗」和「领域配置页批量指派」修改
    │       │
    │       └── CONFIG_DATA（领域配置数据，按 domainId 索引）
    │               ├── dept（责任科室）
    │               ├── checklists[]（检查表配置）
    │               │       ├── name, cycle, scope, person, dept, enabled
    │               │       └── selectedObjects[]（指定范围时的对象+频次覆盖）
    │               ├── scan（扫码责任）
    │               │       ├── person, dept, linkedChecklist, enabled
    │               └── hazard / hazards（隐患责任）
    │                       ├── type, responder, deadline, reviewer, reviewPerson, enabled
    │                       ↑ 被各弹窗修改
    │
    └── INCOMPLETE_ITEMS（未完成检查项静态数据，按 domainId 索引）
            ├── name, date, person
            └── viewIncomplete() 读取或 generateIncompleteItems() 动态生成
```
