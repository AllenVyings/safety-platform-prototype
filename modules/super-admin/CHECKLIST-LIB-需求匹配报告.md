## 一、需求概览（PRD第13章）

### 1.1 功能架构

```
检查库管理（三Tab结构）
├── Tab1: 检查表（左右分栏：左树+右列表）
├── Tab2: 检查项列表（全宽列表）
└── Tab3: 知识图谱（左右分栏：左实体+右可视化）
```

### 1.2 核心功能点

| 功能模块 | 需求描述 | 优先级 |
|---------|---------|--------|
| 检查表管理 | 增删改查、领域筛选、状态管理 | P0 |
| 检查项管理 | 独立维护、关联隐患/法规、批量操作 | P0 |
| 知识图谱 | 6类实体可视化、关联展示、交互操作 | P1 |
| 检查库引用 | 分组列表、搜索筛选、批量导入 | P0 |
| 精准推荐 | 基于领域小类自动推荐检查项 | P1 |
