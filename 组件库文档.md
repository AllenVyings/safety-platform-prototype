## 2. 数据展示组件

### 2.1 统计卡片
```html
<div class="stat-cards">
  <div class="stat-card">
    <div class="stat-icon blue">🏢</div>
    <div class="stat-content">
      <div class="stat-value">156</div>
      <div class="stat-label">企业总数</div>
    </div>
  </div>
</div>
```

**变体**：
- `stat-icon.blue` - 蓝色主题
- `stat-icon.green` - 绿色主题（成功）
- `stat-icon.orange` - 橙色主题（警告）
- `stat-icon.gray` - 灰色主题（禁用）

### 2.2 数据表格
```html
<div class="table-wrap">
  <table>
    <thead>
      <tr>
        <th>企业名称</th>
        <th>状态</th>
        <th>操作</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>创安电子</td>
        <td><span class="tag tag-green">启用</span></td>
        <td>
          <button class="btn-link">编辑</button>
          <button class="btn-link">删除</button>
        </td>
      </tr>
    </tbody>
  </table>
  <div class="pagination">...</div>
</div>
```

## 3. 表单组件

### 3.1 基础表单
```html
<div class="form-group">
  <label class="form-label">企业名称<span class="required">*</span></label>
  <input type="text" class="form-input" placeholder="请输入企业名称">
  <div class="form-hint">2-50个字符</div>
</div>
```

### 3.2 下拉选择
```html
<div class="form-group">
  <label class="form-label">状态</label>
  <select class="form-select">
    <option value="">全部</option>
    <option value="active">已启用</option>
    <option value="inactive">已禁用</option>
  </select>
</div>
```

### 3.3 开关组件
```html
<div class="form-group">
  <label class="form-label">状态</label>
  <div class="switch-wrapper">
    <div class="switch active" onclick="toggleSwitch(this)"></div>
    <span class="switch-label">启用</span>
  </div>
</div>
```

## 4. 弹窗组件

### 4.1 标准弹窗
```html
<div class="modal-overlay" id="modalId">
  <div class="modal-dialog" style="width: 700px;">
    <div class="modal-header">
      <span class="modal-title">弹窗标题</span>
      <button class="modal-close" onclick="closeModal('modalId')">×</button>
    </div>
    <div class="modal-body">
      <!-- 表单内容 -->
    </div>
    <div class="modal-footer">
      <button class="btn btn-default" onclick="closeModal('modalId')">取消</button>
      <button class="btn btn-primary" onclick="save()">保存</button>
    </div>
  </div>
</div>
```

### 4.2 信息板块
```html
<div class="info-section">
  <div class="section-title">基本信息</div>
  <!-- 表单内容 -->
</div>
```
