# 安全码综合管理平台 V5.0 原型说明

**版本**: V5.0
**日期**: 2026-05-14
**状态**: 演示版

---

## 一、原型简介

安全码综合管理平台是一个面向政府监管部门和企业的安全管理信息化系统，提供领域分类管理、检查表配置、监管单位配置等功能。

### 三大端介绍

| 端 | 用户 | 核心功能 |
|---|------|---------|
| **超管端** | 平台管理员 | 领域小类管理、政府组织架构、系统配置 |
| **政府端** | 监管人员 | 领域监管、企业管理、任务派发 |
| **企业端** | 企业用户 | 管控对象管理、自查记录、隐患整改 |

## 二、快速开始

### 方式一：服务器模式（推荐）

1. **启动服务器**
   - 双击 `start-server.bat`
   - 或在命令行运行：`python -m http.server 8765`

2. **访问原型**
   - 浏览器打开：`http://localhost:8765/index.html`
   - 或：`http://127.0.0.1:8765/index.html`

3. **切换端点**
   - 左上角切换：超管端 / 政府端 / 企业端

4. **标注功能**（开发模式）
   - 点击顶栏「🔧 开发」按钮切换到开发模式
   - 页面内出现蓝色圆形标注徽章，点击查看业务规则、交互说明等 PRD 关联信息
   - 点击顶栏「📋 标注」按钮打开标注总览面板，可按分类筛选，点击标注跳转到对应页面

### 方式二：离线查看

1. 解压后直接双击 `index.html`
2. 浏览器自动打开（file:// 协议）
3. ⚠️ 部分功能可能受限（如组件动态加载）

## 四、交互说明

### 检查表配置（新增/编辑）

1. 点击「+ 新增检查表」打开弹窗
2. 填写检查表名称、频次、过滤节假日
3. 配置检查内容：
   - 点击「+ 新增检查项」添加检查项
   - 点击「+ 添加检查内容」添加检查内容
   - 所有编辑在弹窗内完成，点击「确定」统一保存
4. 点击「保存」提交

### 监管单位配置

1. 在新增/编辑弹窗中点击「配置监管单位」
2. 三个页签：行业监管 / 专业监管 / 属地监管
3. 左侧勾选单位，右侧显示已选列表
4. 属地监管默认全选，不可取消

## 附录：详细设计摘要

### 领域小类新增流程

```
超管登录
  ↓
进入"领域小类管理"模块
  ↓
点击"新增领域小类"
  ↓
填写领域小类基本信息
  ├─ 行业大类（必填，下拉选择）
  │   ├─ 公共场所类
  │   ├─ 建设工程类
  │   ├─ 交通运输类
  │   ├─ 工业制造类
  │   ├─ 城市运行类
  │   ├─ 危险化学品类
  │   └─ 其他类
  │
  ├─ 领域小类名称（必填，文本输入）
  │   └─ 如：生产车间、商业综合体等
  │
  ├─ 启用状态（必填，单选）
  │   ├─ 启用
  │   └─ 禁用
  │
  └─ 领域小类描述（可选，文本输入）
      └─ 对该领域小类的详细描述
  ↓
保存领域小类基本信息
  ↓
系统自动生成领域小类编码
  ├─ 编码规则：行业大类编码 + 下划线 + 序号
  ├─ 示例：MANUFACTURING_001
  └─ 显示给超管确认
  ↓
进入"配置监管单位"步骤
```

### 监管单位配置

**监管单位类型**：
- 行业主管部门（如：工业和信息化局）
- 专业监管部门（如：应急管理局）
- 属地监管部门（如：南山区政府）

**配置规则**：
- 每个类型可配置多个具体单位
- 属地监管默认全选所有街道，不可取消

### 检查表配置

**检查表字段**：
- 检查表名称（必填）
- 检查频次（必填）：每日/每周/每月/每季/每年
- 是否过滤节假日（开关）

**检查内容层级**：
- 一级：检查项（分类）
- 二级：检查内容（具体检查点）
- 三级：检查标准（选填）

**检查结果选项**：
- 正常（safe）
- 异常（hazard）
- 不适用（na）

### 四种业态模式

| 模式 | 适用场景 | 企业端菜单/特性 |
|------|---------|----------------|
| **基础模式** | 常规企业日常管理 | 企业基础信息、组织架构管理、企业人员管理、安全管控对象、履职任务管理、检查记录管理、隐患整改管理 |
| **项目模式** | 工程项目类企业 | 项目基础信息、组织架构管理、项目人员管理、安全管控对象、履职任务管理、检查记录管理、隐患整改管理 |
| **特殊场景模式** | 单独的场所，受多方监管 | 可关联给企业、项目、政府单位；场所独立管理，多方共享查看 |
| **其他模式** | 未归类或混合类型 | 企业端页面为专属定制页面，不采用标准菜单结构 |

### 数据模型

**领域小类（IndustrySubcategory）**：
```
├─ industry_category_id（外键，关联行业大类）
├─ subcategory_name（领域小类名称）
├─ subcategory_code（自动生成编码）
├─ status（启用/禁用）
├─ description（描述）
├─ created_at（创建时间）
└─ updated_at（更新时间）
```

**监管单位配置（DomainSupervisor）**：
```
├─ domain_id（外键，关联领域小类）
├─ supervisor_type（监管类型：行业/专业/属地）
├─ org_id（外键，关联政府组织架构）
└─ created_at（创建时间）
```

**检查表（Checklist）**：
```
├─ domain_id（外键，关联领域小类）
├─ name（检查表名称）
├─ interval（检查间隔）
├─ unit（间隔单位：day/week/month/quarter/year）
├─ times（检查次数）
├─ skip_holiday（是否过滤节假日）
├─ items（检查项列表，JSON）
└─ created_at（创建时间）
```

### 接口设计

**POST /api/domain/save**
- 描述：新增/编辑领域小类
- 参数：基本信息、监管单位列表、检查表列表
- 返回：领域小类ID

**POST /api/checklist/batch-save**
- 描述：批量保存检查表
- 参数：检查表列表（含检查项、检查内容）
- 返回：保存结果
- 特性：支持事务回滚，N次请求合并为1次
